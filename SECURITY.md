# Sicherheit / Security

**Deutsch** · [English](#english)

Sicherheitslücken bitte **nicht** als öffentliches Issue melden, sondern vertraulich über
[„Report a vulnerability“](https://github.com/jdeixi/3d-printstudio-install/security/advisories/new)
(Reiter „Security“ dieses Repositorys). Hilfreich sind die betroffene Version, die Betriebsart
(Docker oder Desktop-App) und eine kurze Beschreibung, wie sich das Problem nachvollziehen lässt.

Unterstützt wird jeweils die aktuelle Version; Korrekturen erscheinen als neues Release und lassen sich
in der App unter Grundeinstellungen → Update installieren.

<a id="english"></a>

## English

Please do **not** report security vulnerabilities as a public issue; use
[“Report a vulnerability”](https://github.com/jdeixi/3d-printstudio-install/security/advisories/new)
(the “Security” tab of this repository) instead. Please include the affected version, the mode of
operation (Docker or desktop app) and a short description of how to reproduce the problem.

Only the current version is supported; fixes are published as a new release and can be installed in the
app under Basic settings → Update.
